## exp1 问题诊断

### 问题一：val PSNR 震荡（最核心的评估缺陷）

```
Epoch 15: 20.77 dB
Epoch 16: 20.33 dB  ← 下降了？
Epoch 17: 20.60 dB
Epoch 18: 20.96 dB  ← 又上去了？
```

**根本原因**：验证时每张图的雾浓度 `t` 也是随机采样的，导致每次 val 结果不可比较。不是模型变差了，是评估本身有噪声。

```
训练用随机 t → 正确（数据增强）
验证用随机 t → 错误（应该固定，才能反映模型真实进步）
```

### 问题二：epoch 5 后 loss 卡死

loss 在 epoch 5 就基本停止下降，原因是物理公式的数值问题：

```python
J = (I - 1) / (K + 1e-6) + 1
J = J.clamp(0, 1)   ← 截断操作阻断梯度
```

当 K ≈ 0 时，J 的值会超出 [0,1] 范围，clamp 截断后该像素的梯度为 0，网络学不到任何信号。1,599 参数太少，K 的预测不够精确，截断比例过高。

> [!IMPORTANT] 关键认识
> `clamp` 是不可微的边界操作——被截断的像素既不贡献 loss，也不贡献梯度。模型能力越弱，被截断的像素越多，训练越停滞。这是一个正反馈的恶性循环。

## exp2 改进方案

**改进一：固定 val 的 t**

```python
fixed_t = None if self.split == "train" else 0.5
hazy, t = synthesize_haze(clean, t=fixed_t)
```

验证集统一用 t=0.5（中等浓度雾），每次评估结果可复现、可比较。

**改进二：增大模型容量**

| 层 | exp1 通道 | exp2 通道 |
|----|----------|----------|
| conv1 | 3→3 | 3→8 |
| conv2 | 3→3 | 8→8 |
| conv3 | 6→3 | 16→8 |
| conv4 | 6→3 | 16→8 |
| conv5 | 6→3 | 16→3 |
| **参数量** | **1,599** | **10,539** |

**改进三：K 加偏置防止除零**

```python
K = self.relu(self.conv5(...)) + 0.1   # 保证 K 至少为 0.1，避免除以接近 0 的值
```

去掉 `1e-6` 的保护，改用 `+0.1` 的偏置——既保证数值稳定，又让梯度在 K 较小时仍然有意义。

## exp2 诊断

val PSNR 仍在震荡（范围 21.47–24.46 dB），即使已固定 t=0.5。
原因：`lr=1e-4` 对后期精细调整仍然过大，优化器在最优点附近来回跳。

> [!NOTE] 反复出现的规律
> SegFormer exp1 和 AOD-Net exp2 都出现了"后期 val 指标震荡"。
> 根因相同：固定学习率在后期太大。
> 解法相同：**LR Scheduler（CosineAnnealingLR）**。

## 可视化结果（2026-06-02）

`visualize.py`：合成雾验证集，6 张样本，3 列对比（有雾 / 去雾 / 清晰 GT）

## 真实雾图推理（2026-06-02）

`infer.py`：7 张真实雾天照片（街景、公路），无 GT，仅做视觉对比

**观察结果：**
- 建筑、风景整体**变暗**，颜色偏深
- 去雾有一定效果，但不如合成雾干净

**原因分析（域差距 Domain Gap）：**

```
训练时假设：A = 1.0（纯白大气光）
真实雾实际：A ≈ 0.6~0.8（灰色大气光）
```

模型学到的去雾逻辑 ≈ 「减去白色层 + 增强对比度」。真实雾是灰色的，模型按白色处理，减过头，图像被压暗。

> [!IMPORTANT] 核心认识
> 模型"有一些效果"说明大气散射物理公式是真实的，模型学到了部分真实规律。
> 效果不完整说明参数分布（A、t 的范围）和真实世界不符——这是**数据的问题，不是模型或反向传播的问题**。

## 图像复原的本质局限（概念层面）

去雾是**病态问题（ill-posed problem）**：给定有雾图，理论上对应无数张合理的清晰图。

| 评估维度 | 指标 | 是否需要 GT |
|---------|------|-----------|
| 像素精度 | PSNR / SSIM | 需要 |
| 感知质量 | LPIPS（神经网络感知相似度）| 需要 |
| 自然图像统计 | NIQE / BRISQUE | **不需要** |
| 人类主观评分 | MOS | **不需要** |

MSE loss 的根本问题：它让模型预测条件均值，而不是"最合理的那一个"。GAN / Diffusion 类方法解决的就是这个问题。

## 改进路线总结

| 路线 | 做法 | 解决的问题 | 代价 |
|------|------|----------|------|
| 改进合成数据 | 随机 A∈[0.7,1.0]，t 随深度变化 | 减小域差距 | 低，直接修改 dataset.py |
| 无监督对抗训练 | GAN / CycleGAN，用真实雾图无 GT 训练 | 从根本上接触真实分布 | 高，训练复杂，容易不稳定 |
| 两步结合 | 合成预训练 → 真实域对抗微调 | 最完整 | 最高 |

实践中通常先做路线一，再做两步结合。

## 下一步（exp3，可选）

```python
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=EPOCHS)
# 每个 epoch 结束后调用
scheduler.step()
```
