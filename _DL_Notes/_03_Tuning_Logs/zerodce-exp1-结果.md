## 诊断：模型几乎没有学到增强

### 现象
Loss 在 epoch 5 就停止下降，此后 25 个 epoch 在 1.27~1.28 间震荡。
val PSNR 全程在 9.4~9.6 dB 范围内，无实质性提升。

### 根本原因一：Loss 间冲突

```
W_tv = 200  vs  W_exp = 10
光照平滑 权重是曝光控制的 20 倍
```

模型发现的最小阻力路径：alpha ≈ 0（几乎不增强）
→ TV loss 满意（alpha 均匀=0，梯度为零）
→ 曝光 loss 略有损失，但代价远小于改变 alpha

> [!IMPORTANT] 退化解的实例
> 这是实际遇到的退化解（Trivial Solution）：模型输出接近原图，大部分 loss 接近最小值，但任务根本没有完成。

### 根本原因二：合成数据与 loss 设计不匹配

Zero-DCE 的 4 个 loss 是为**真实低光照图像**设计的（LOL 数据集）。
我们用 `pixel^gamma` 合成暗图，产生的是**均匀、无噪声的暗图**，缺少真实暗图的统计特征，loss 的优化方向在这个数据分布上不对齐。

---

## 核心认识

1. **无监督 loss 设计比有监督难得多**：需要保证 loss 组合没有"比完成任务更容易的捷径"
2. **Loss 权重是超参数**：W_tv=200 太强，压制了增强。真正调参的经验是：先降低 W_tv，观察 loss 曲线变化
3. **数据和 loss 必须匹配**：Zero-DCE 的 loss 假设输入是真实低光照图；换成合成 gamma 暗图，假设不成立

## exp2（2026-06-03）：W_TV=50

| 参数 | 值 |
|------|-----|
| Loss 权重 | spa:1  exp:10  col:5  **tv:50** |
| 其余配置 | 同 exp1 |

**训练曲线（节选）：**

| Epoch | loss | val PSNR |
|-------|------|---------|
| 01 | 1.3640 | 8.10 dB |
| 05 | 1.2882 | 8.14 dB |
| 06 | 1.2924 | 8.07 dB |
| 07 | 1.2900 | 8.15 dB |
| 08 | 1.2920 | 8.11 dB |
| 09 | 1.2930 | 8.11 dB |
| 10 | 1.2910 | 8.15 dB ← 手动停止 |

**诊断：平台期，epoch 5 后 loss 在 1.288~1.293 震荡**

W_TV=50 使模型脱离了完全退化解（loss 比 exp1 高，说明有在增强），但 W_TV:W_EXP = 5:1 仍然太强，模型陷入"轻微增强但被 TV 约束"的局部最优。

> [!NOTE] 重要观察
> exp2 的平台期 loss（1.29）比 exp1（1.27）还**高**。
> 这说明 exp1 找到了更"干净"的退化解（alpha≈0，TV=0），而 exp2 是在一个更混乱的中间状态。
> 平台期 loss 更高 ≠ 模型更好，需要结合可视化判断。

## exp3（2026-06-03 进行中）：W_TV=20 + 分量 log

| 参数 | 值 |
|------|-----|
| Loss 权重 | spa:1  exp:10  col:5  **tv:20** |
| W_TV:W_EXP 比 | **2:1**（vs exp2 的 5:1）|
| 新增 | 每 epoch 打印 spa/exp/col/tv 各分量 |

**调参逻辑：**

```
exp1: W_TV=200 (20:1) → 退化解，完全不增强
exp2: W_TV=50  (5:1)  → 局部最优，轻微增强但卡住
exp3: W_TV=20  (2:1)  → 期望 L_exp 能主导，模型真正学到变亮
```

**观察重点：**
- `exp` 分量是否持续下降（=模型在学习变亮）
- `tv` 分量占 total loss 的比例是否合理
- loss 是否在 epoch 10 后仍有下降趋势

## 如果 exp3 仍失败

| 方案 | 具体做法 |
|------|---------|
| W_TV=10 | 降到与 W_EXP 等权，彻底解除 TV 压制 |
| 换真实数据 | 使用 LOL 数据集（真实低光照图，loss 统计假设成立）|
| 调曝光目标 | E=0.6 → E=0.5（gamma=3 暗图比真实低光照更极端）|
