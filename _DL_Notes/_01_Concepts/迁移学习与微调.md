# 迁移学习与微调

上级笔记：[[CV学习总路线图]]
相关笔记：[[SegFormer-语义分割入门]]

---

## 核心思想

从头训练一个深度学习模型需要大量数据和时间。
迁移学习的思路是：**先用别人在大数据集上训好的权重作为起点，再在自己的任务上接着训练。**

```
大数据集（ImageNet, 130万张）
        ↓ 预训练
   强大的特征提取能力
        ↓ 迁移
  小数据集（VOC2012, 1464张）
        ↓ 微调
    适应新任务的模型
```

这比从头训练快得多，因为模型已经"认识"边缘、纹理、形状等基础视觉特征，只需要学习"怎么把这些特征对应到新任务的类别"。

---

## 编码器 vs 解码器：谁在迁移，谁在学习

以 SegFormer 微调 VOC2012 为例：

```
SegFormer
├── 编码器（MiT-B0）← 加载 ImageNet 预训练权重，特征提取能力已有
└── 解码器（All-MLP）← 随机初始化，需要从头学习"如何分割 21 类"
```

训练时：
- 编码器权重从一个好的起点开始，只需要小幅调整（"微调"）
- 解码器从随机噪声开始，需要较大幅度更新

这就是为什么微调用很小的学习率（`lr=6e-5`）——避免把编码器已经学好的特征破坏掉。

## HuggingFace 加载报告解读

运行 `from_pretrained("nvidia/mit-b0", num_labels=21, ignore_mismatched_sizes=True)` 时，会打印一张权重加载报告：

```
Key                        | Status
---------------------------+-----------
classifier.bias            | UNEXPECTED
classifier.weight          | UNEXPECTED
decode_head.classifier.*   | MISSING
decode_head.linear_*       | MISSING
...
```

### UNEXPECTED（意外出现的键）

预训练权重文件里**有**，但当前模型结构**不需要**的参数。

在这个例子里，`nvidia/mit-b0` 原本是一个图像分类模型（1000类 ImageNet），它有一个 `classifier` 头。
我们把它改造成分割模型后，这个分类头就不需要了——直接丢弃，不会影响模型。

> [!NOTE] 什么时候 UNEXPECTED 是问题？
> 如果你加载的是**完全相同架构**的权重（比如加载自己上次保存的模型），出现 UNEXPECTED 就说明模型结构和存档不匹配，需要排查。
> 但从**不同任务的预训练权重**迁移时，UNEXPECTED 完全正常。

### MISSING（缺失的键）

当前模型结构**需要**，但预训练权重文件里**没有**的参数。

这些是我们新加的解码头（`decode_head.*`）。因为原来的模型没有这些层，预训练权重里自然没有对应的值，所以这些参数会被**随机初始化**——训练时主要就是在学这部分。

### ignore_mismatched_sizes=True 的作用

告诉 HuggingFace："我知道新旧模型的结构不一样，请允许这种不匹配，丢弃 UNEXPECTED，随机初始化 MISSING。"
如果不加这个参数，加载时会直接报错。

## 完整流程回顾（SegFormer 微调）

```
1. from_pretrained("nvidia/mit-b0")
        ↓
2. 下载预训练权重（~14MB，ImageNet 分类模型）
        ↓
3. 替换分类头 → 分割解码头（21类）
   - 旧分类头：UNEXPECTED → 丢弃
   - 新解码头：MISSING → 随机初始化
        ↓
4. 编码器权重完整保留（已有特征提取能力）
        ↓
5. 用 VOC2012 训练：
   - 解码头：从随机初始化开始，快速学习
   - 编码器：从好的起点微调，小幅调整
```

## 为什么用 ImageNet 预训练而不是 ADE20K 预训练

HuggingFace 上也有在 ADE20K（分割数据集）上预训练好的 SegFormer 权重，比如 `nvidia/segformer-b0-finetuned-ade-512-512`。

| 权重来源 | 优点 | 缺点 |
|---------|------|------|
| ImageNet 分类预训练（我们用的）| 编码器特征通用，适合学习微调流程 | 解码头需要从头学 |
| ADE20K 分割预训练 | 解码头已经学会分割，微调更快 | 直接用别人的结果，学不到解码头的训练过程 |

入门阶段用 ImageNet 预训练更有学习价值，能看到解码头从随机到收敛的完整过程。
